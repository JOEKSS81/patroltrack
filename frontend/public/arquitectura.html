🐕 PATROLTRACK

Com funciona l'app · de quina manera i amb què

1 · Funcionament (quan fas servir l'app)

📱 El teu mòbil — PWA
patroltrack.pages.dev · React + Vite
  • Mapa · Radar · Stats · Calendari · Historial
  • El radar GPS calcula la probabilitat al mòbil amb les deteccions descarregades
  • Botó “+ Reportar” per afegir avisos a mà
↓
HTTPS · cada 15s llegeix dades · report = POST amb token
☁️ Worker — API (sense servidor)
patroltrack-api…workers.dev
  • GET /api/detections · /health · /probability
  • POST /api/ingest (protegit amb token)
  • extractor: llegeix el missatge i en treu patrulla / zona / tipus
  • No està sempre encès: es desperta a cada petició
↓
🗄️ D1 — base de dades (SQLite)
taula “detections”
  • Desa cada detecció: data, hora, zona, tipus, confiança…

2 · D'on surten les dades

✍️ Missatge de patrulla
  • Ex: “Mossos a la N-II km 45, cuidado”
  • El copies tu i l'enganxes al botó “+ Reportar”
↓
Worker → extractor → D1
  • Si sembla una alerta de patrulla → es desa ✅
  • Si no → es descarta
⚠️ Ara mateix NO hi ha captura automàtica de WhatsApp/Telegram. L'única entrada de dades és el botó “+ Reportar” manual. (La captura automàtica és la peça que queda pendent.)

💻 Local (Mac)
codi font — on s'edita
↓   ↓
🐙 GitHub
  • commit + push
  • Còpia de seguretat + historial

Idees clau

  • Tot corre a Cloudflare (gratis) → no depèn del teu Mac; funciona 24/7.
  • El Worker no està sempre encès: es desperta a cada petició (per això és gratis i ràpid).
  • El radar no envia res: descarrega les deteccions i calcula la probabilitat al teu mòbil.
  • Les probabilitats són reals: si no hi ha deteccions en una zona/hora → 0% (cap alarma inventada).
  • L'única entrada de dades és “+ Reportar” (captura automàtica pendent).
